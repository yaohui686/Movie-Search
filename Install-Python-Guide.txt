  影视检索 · Python 安装指引（1 分钟搞定）
════════════════════════════════════════════════

这个工具需要 Python 3.10 以上版本。检测到你电脑上还没有，
按下面三步装好即可，装完重新双击「影视检索.cmd」就能用。

────────────────────────────────────────
第一步：下载安装包（三选一）
────────────────────────────────────────

① 本项目 Release 离线包（推荐，不用翻墙）
   打开 github.com/yaohui686/Movie-Search/releases
   下载 Assets 里的 python-xxx-amd64.exe

② Python 官网
   打开 www.python.org/downloads
   点黄色大按钮 Download Python 3.x.x

③ 微软商店
   开始菜单搜 Microsoft Store → 搜 python → 安装
   （商店版对本工具的兼容性略差，优先用①②）

────────────────────────────────────────
第二步：安装时必看的一个勾
────────────────────────────────────────

安装第一屏的底部有一个小勾：

    ☑ Add python.exe to PATH

【务必勾上它】再点 Install Now！
不勾的话系统找不到 python，双击启动器还是报错。

────────────────────────────────────────
第三步：验证
────────────────────────────────────────

装完直接重新双击「影视检索.cmd」。
如果弹出的是浏览器自动打开 Python 官网，说明 PATH 还没生效：

  · 重启一次电脑，或者
  · 检查第一屏那个勾是否漏了（重新跑安装器选 Modify 即可补勾）

────────────────────────────────────────
常见报错对照
────────────────────────────────────────

· 双击后秒弹 Microsoft Store 商店页面
  → 你的电脑装了微软放的「假 python」占位。关掉它：
  设置 → 应用 → 高级应用设置 → 应用执行别名
  → 把 python.exe 和 python3.exe 两个开关关掉
  → 重新双击启动器

· 报 [ERROR] exit code 9009
  → 同上，系统找不到真正的 python，按上面步骤处理

· 其他报错
  → 看 logs\crash.log 里的堆栈，或去仓库 Issues 反馈
